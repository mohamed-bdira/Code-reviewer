\section{MongoDB collections}
\label{sec:mongodb-collections}

The platform persists five document collections in MongoDB (Mongoose models under \texttt{backend/models/}). Relationships use stored \texttt{ObjectId} references and denormalized strings; uniqueness is enforced with indexes, not SQL foreign keys.

\begin{table}[htbp]
  \centering
  \caption{Collection purposes (logical data model).}
  \label{tab:collection-purposes}
  \begin{tabular}{@{}p{0.22\textwidth}p{0.72\textwidth}@{}}
    \toprule
    \textbf{Collection} & \textbf{Purpose} \\
    \midrule
    \texttt{users} &
    Operator accounts created or updated on GitHub OAuth sign-in (\texttt{githubId}, \texttt{githubLogin}, email). JWT session identifies the operator. \\
    \texttt{installations} &
    GitHub App installation bindings: links a platform user to a GitHub \texttt{installationId}, account login, and account type (User or Organization). \\
    \texttt{repoconfigs} &
    Per-repository review policy: focus areas, enforcement level, custom rules, merge minimum score, optional AST-grep flag, and associated installation id. Unique per \texttt{(userId, repoFullName)}. \\
    \texttt{apikeys} &
    Operator-issued API credentials: label, lookup prefix, bcrypt hash of the secret (plaintext shown once at creation). Revocation via \texttt{revokedAt}. \\
    \texttt{prreviewfindings} &
    AI-detected issues from pull request reviews: repository, PR number, category, file path, line range, description, first/last seen. Upserted by \texttt{dedupeKey}. \\
    \bottomrule
  \end{tabular}
\end{table}

\section{Authentication routes (GitHub only)}
\label{sec:auth-routes-github}

Email/password registration and login are out of scope for the documented product flow; operators authenticate exclusively via GitHub OAuth.

\begin{table}[htbp]
  \centering
  \caption{Authentication API routes and \texttt{users} collection access.}
  \label{tab:auth-routes}
  \begin{tabular}{@{}lllp{0.38\textwidth}@{}}
    \toprule
    \textbf{Method} & \textbf{Path} & \textbf{Collection} & \textbf{Action} \\
    \midrule
    GET  & \texttt{/api/auth/github/start}    & ---     & Redirect browser to GitHub OAuth authorize URL. \\
    GET  & \texttt{/api/auth/github/callback} & \texttt{users} & Exchange code; upsert user; redirect to SPA \texttt{/auth/finish} with JWT. \\
    GET  & \texttt{/api/auth/me}              & \texttt{users} & Return current user profile (\texttt{requireAuth}: JWT or API key). \\
    \bottomrule
  \end{tabular}
\end{table}

\section{Collection-specific API routes}
\label{sec:collection-routes}

\subsection{\texttt{users}}
Indirect access: every \texttt{requireAuth} request resolves the operator from JWT (post-GitHub sign-in) or from \texttt{apikeys} verification.

\subsection{\texttt{installations}}

\begin{table}[htbp]
  \centering
  \caption{Routes that read or write \texttt{installations}.}
  \label{tab:routes-installations}
  \begin{tabular}{@{}lllp{0.36\textwidth}@{}}
    \toprule
    \textbf{Method} & \textbf{Path} & \textbf{Auth} & \textbf{Action} \\
    \midrule
    GET    & \texttt{/api/installations}           & \texttt{requireAuth}   & List installations for current user. \\
    POST   & \texttt{/api/installations}           & \texttt{requireAuth}   & Link installation by numeric \texttt{installationId}. \\
    DELETE & \texttt{/api/installations/:id}       & \texttt{requireAuth}   & Delete installation document. \\
    GET    & \texttt{/api/github/install}          & \texttt{requireAuth}   & HTTP redirect to GitHub App install page. \\
    POST   & \texttt{/api/github/install-link}     & \texttt{requireAuth}   & JSON response with install URL (state JWT). \\
    GET    & \texttt{/api/github/setup}            & State JWT (callback)   & Upsert installation after GitHub redirect. \\
    GET    & \texttt{/api/dashboard/summary}       & \texttt{requireAuth}   & Include installations in dashboard snapshot. \\
    POST   & \texttt{/api/webhooks/github}         & Webhook signature      & Resolve tenant by \texttt{installation.id}. \\
    GET    & \texttt{/api/repo-configs/available}  & \texttt{requireAuth}   & Validate installation ownership; list repos via GitHub API. \\
    \bottomrule
  \end{tabular}
\end{table}
